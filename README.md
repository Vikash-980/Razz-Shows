
# 🎬 Razz Shows - Movie & Show Discovery Platform

Razz Shows is a sleek and modern web application designed for discovering movies and TV shows. It provides a seamless user experience to explore trending content, view details, and stay updated with the latest in entertainment.

## ✨ Features

- **🔥 Trending Content:** Stay updated with the most popular movies and shows.
- **🔍 Smart Search:** Easily find your favorite movies or actors.
- **📱 Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens.
- **🎨 Modern UI:** Built with a focus on clean aesthetics and smooth navigation.
- **⚡ Fast Performance:** Hosted on Vercel for lightning-fast loading speeds.

## 🚀 Getting Started

Follow these steps to run the project locally:

### 1. Clone the Repository
```bash
git clone [https://github.com/your-username/razz-shows.git](https://github.com/your-username/razz-shows.git)
cd razz-shows

npm install

REACT_APP_API_KEY=your_api_key_here

npm start
```

## 🏗️ Project Architecture & Structure

A clear overview of the project's directory structure and how the files are organized for scalability.

### 📂 Directory Tree
```text
razz-shows/
├── public/                 # Static assets (images, icons, robots.txt)
├── src/
│   ├── assets/             # Global styles, images, and fonts
│   ├── components/         # Reusable UI components (Navbar, Footer, Cards)
│   │   ├── common/         # Buttons, Inputs, Loaders
│   │   └── layout/         # Header, Footer, Sidebar
│   ├── hooks/              # Custom React hooks (useFetch, useAuth)
│   ├── pages/              # Main route pages (Home, MovieDetails, Search)
│   ├── services/           # API call logic (Axios/Fetch configurations)
│   ├── store/              # State management (Redux/Context API)
│   ├── utils/              # Helper functions and constants
│   ├── App.js              # Main App entry point & Routing
│   └── index.js            # React DOM rendering
├── .env                    # Environment variables (API Keys)
├── package.json            # Project dependencies & scripts
└── README.md               # Project documentation

```
